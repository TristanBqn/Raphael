PORTE 1

le rappel
UserPromptSubmit≈ 0,65 s
  1. masque les secrets, enregistre le message
  2. relit les 2 échanges précédents, coupés à 300 caractères
  3. ouvre les tiroirs utiles
  4. recherche hybride, sens + mots : 12 candidats
  5. Jev estime la probabilité, de 0 à 1, que chaque souvenir corresponde au message ; le code garde ceux qui passent le seuil
  6. injecte au plus 5 souvenirs dans le contexte de Claude
